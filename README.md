# voiceagent — Open Slot AI pitch deck

Browser presentation (deck-kit). **Live site:** GitHub Pages → `https://bagherhasani.github.io/voiceagent/`

## Update the live link

1. Edit `deck.html`
2. Run `./publish.sh` (copies to `index.html`)
3. `git add deck.html index.html assets` → commit → push

## Local

Open `deck.html` or `index.html` in Chrome. Arrow keys to advance; Play on the demo slide.
